✅ Task Manager MCP Server

A Model Context Protocol (MCP) server that demonstrates tool-level OAuth scopes, secured by Descope auth and built with FastMCP 3. Every request is authenticated by Descope, and each tool is authorized individually against the scopes in the caller's token.

Tools & Required Scopes

Tools whose scope you don't hold are hidden from tools/list — clients only ever see what their token allows.

Tool Required scope Description
list_tasks tasks:read List all tasks
get_task tasks:read Fetch a single task by id
create_task tasks:write Create a new task
complete_task tasks:write Mark a task as done
delete_task tasks:admin Delete a task (privileged)
purge_completed tasks:write tasks:admin Delete all completed tasks (requires both scopes)

Troubleshooting

If you encounter authentication issues, try clearing the cached authentication files: 

rm -rf ~/.mcp-auth

If a tool you expect is missing, confirm the scope is granted on your token (decode your access token to inspect its scopes) and that the scope is defined on your Descope MCP Server.
